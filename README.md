Remote Sensing Image Fusion using Deep Neural Network with Multi — Skip Connections

The act of image fusion from several satellite sensors to produce a more thorough and 
precise depiction of the Earth's surface or atmosphere is known as satellite data fusion. 
High-spatial and spectral-resolution remote sensing imagery is crucial for 
environmental protection, geological research, and other disciplines. A particular kind 
of image fusion known as "pansharpening" creates a single high-resolution image by 
fusing together two lower-resolution multispectral (MS) images and a high-resolution 
panchromatic (PAN) image. This thesis combines several state-of-the-art feature 
enhancement and aggregation techniques to present an effective deep neural network 
model. The study area of West Godavari district, Andhra Pradesh, was covered by 
Landsat 8 satellite photos, which were used as input images to create multispectral (MS) 
images, which mix RGB and NIR bands. A deep neural network model with multi
switch – skip connection was proposed in this study. After preprocessing the data, those 
inputs were used as inputs for our proposed model, "ImgFuseNet." When compared to 
other well-known picture fusion techniques, the suggested model performs better, with 
the greatest Q value of 0.982 and a high PSNR value of 8.582. With the maximum QNR 
value of 0.2673, this fused image shows very little spectral and spatial distortion. For 
the fused image, a supervised land use-land cover (LULC) classification has been 
implemented as a part of fused image usage in the field of remote sensing, and the 
results are compared to the original multispectral image (MS). The outcomes 
demonstrated that, in comparison to its original image, the fused image performs well 
in capturing different classes while using a support vector machine (SVM) model with 
an overall accuracy improvement of 1.075%. A significant change in vegetation indices 
like NDVI and NDWI was also observed.
